## 👋 About Me

I'm a software developer interested in **Computer Vision, Robotics, and AI Systems**.

My work focuses on making individual algorithms function reliably **as part of a complete system** — connecting sensor inputs, perception modules, data pipelines, and downstream applications.

- 🔍 **Perception:** Computer vision, robust data processing, lightweight AI
- 🔗 **System Integration:** ROS 2 interfaces, sensor-to-control data flow, cross-module integration
- ⚙️ **Optimization:** Communication bottlenecks, resource usage, reproducible experiments
- 🌱 **Currently Exploring:** Java backend development, multithreading, databases, MLOps, Physical AI

## 🚀 Selected Work

### 🚗 Autonomous Driving · ROS 2 System Integration

- Integrated heterogeneous sensors with perception and control modules in a ROS 2-based system.
- Defined message structures and interfaces to support collaboration across modules.
- Analyzed communication bottlenecks and reworked the data delivery structure, reducing observed **CPU usage from approximately 60% to 30%** in the project environment.
- Explored robust perception through outlier filtering and lightweight vision techniques.

### 🧠 Edge AI · Audio Spectrogram Transformer Quantization

- Studied **quantization-aware training (QAT)** and analyzed unstable weight and quantization-parameter behavior.
- Automated experiment configuration, repeated runs, and logging using Linux/Bash.
- Compared **FP32 and INT8 inference** on NVIDIA Jetson Orin Nano and evaluated model accuracy.

### 🛠 Developer Tooling · ROS 2 Integration Assistant

- Documented ROS 2 package structures, topics, message formats, and module interfaces to reduce integration friction.
- Developed a **LangGraph-based assistant** to support conversion of Python/C/C++ algorithms into ROS 2 packages.
- Focused on making shared system knowledge reusable across team members.
